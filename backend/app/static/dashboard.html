AEGIS-AEAD extensions
Five medical-domain protocol features
i.  Domain-bound associated data — device ID, department code and session token authenticated with every message.
ii.  Hybrid nonce — hardware serial ⊕ timestamp ⊕ session counter; replay-resistant across reboots and broker failover.
iii. Device identity — challenge–response handshake (HMAC-SHA256) with HKDF-SHA256 session keys.
iv. Dynamic key rotation — per N messages or T seconds, gateway-signed and device-acknowledged.
v.  Authenticated finalization — 128-bit tag verified at the gateway; any tampering aborts the message before AI inference.
